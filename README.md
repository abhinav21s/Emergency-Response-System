# 108 Unified Ambulance Dispatch Demo

A local MERN proof-of-concept that dispatches the nearest available ambulance across both public 108 and private fleets, irrespective of fleet ownership. It uses React, Express, MongoDB Atlas, Socket.io, Leaflet and OpenStreetMap; no API keys or paid mapping services are required.

See [SETUP.md](SETUP.md) to run it and [FEATURES.md](FEATURES.md) for the complete feature list.
